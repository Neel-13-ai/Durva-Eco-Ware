## 4. In-Depth Domain Breakdown & Implementation Summary

### 4.1 Master Data Modules
- **Categories** (`CategoryRepository`):
  - `GET /api/categories`, `GET /api/categories/{id}`, `POST /api/categories`, `PUT /api/categories/{id}`, `DELETE /api/categories/{id}`
  - UI: `CategoryScreen` has FAB for adding, Edit icon for editing, and Delete icon with confirmation dialog.
- **Units of Measurement** (`UnitRepository`):
  - `GET /api/units`, `GET /api/units/{id}`, `POST /api/units`, `PUT /api/units/{id}`, `DELETE /api/units/{id}`
  - UI: `UnitScreen` has Add dialog, Edit dialog, and Delete dialog.
- **Warehouses** (`WarehouseRepository`):
  - `GET /api/warehouses`, `GET /api/warehouses/{id}`, `POST /api/warehouses`, `PUT /api/warehouses/{id}`, `DELETE /api/warehouses/{id}`
  - UI: `WarehouseScreen` supports adding new warehouses, editing code/manager/phone/address, and deleting with confirmation.
- **Products** (`ProductRepository`):
  - `GET /api/products`, `GET /api/products/{id}`, `POST /api/products`, `PUT /api/products/{id}`, `DELETE /api/products/{id}`
  - UI: `ProductListScreen` displays all products; `ProductFormScreen` handles Create & Edit; `ProductDetailScreen` includes Delete action button in AppBar with safety confirmation dialog wired to `productFormControllerProvider.notifier.delete(product.id)`.

### 4.2 Partners & Fleet
- **Suppliers** (`SupplierRepository`):
  - Full CRUD in both API and UI (`SupplierListScreen` has Add FAB, Edit button, and Delete button with confirmation dialog).
- **Customers** (`CustomerRepository`):
  - Full CRUD in both API and UI (`CustomerListScreen` has Add FAB, Edit button, and Delete button with confirmation dialog wired to `customerFormControllerProvider.notifier.delete(customer.id)`).
- **Transporters** (`TransporterRepository`):
  - Full CRUD in both API and UI (`TransporterListScreen` has Add FAB, Edit button, and Delete button with confirmation dialog wired to `transporterFormControllerProvider.notifier.delete(transporter.id)`).
- **Vehicles** (`VehicleRepository`):
  - Full CRUD in both API and UI (`VehicleListScreen` has Add dialog, Edit dialog, and Delete dialog wired to `vehicleFormControllerProvider.notifier.delete(vehicle.id)`).
- **Payment Methods** (`PaymentMethodRepository`):
  - Full CRUD in both API and UI (`PaymentMethodScreen` handles listing, Add dialog, Edit dialog, and Delete confirmation dialog wired to `paymentMethodFormControllerProvider.notifier.delete(method.id)`).

### 4.3 Purchasing & GRN
- **Purchase Orders** (`PurchaseRepository`):
  - Full CRUD: Create PO (`/purchases/new`), Edit PO (`/purchases/:id/edit`), View PO Details (`/purchases/:id`), Delete PO (via confirmation dialog in PO details).
- **Goods Receipt Notes (GRN)** (`GoodsReceiptRepository`):
  - Direct 2-step verification: Create GRN from PO (`/purchases/:id/grn`) updates inventory balance and advances PO status.
- **Vendor Payments** (`VendorPaymentRepository`):
  - Full CRUD: Create Payout (`/purchases/:id/pay`), View Payout Receipt (`/purchases/payments/:id`), Delete Payout (via confirmation dialog in receipt screen).

### 4.4 Sales & Customer Payments

## 5. Architectural Resiliency Note: IIS WebDAV 405 Handling

During live testing against `https://api-dev.durvaecoware.com`, IIS returns `405 Method Not Allowed` for `PUT` and `DELETE` requests because WebDAV is enabled on the server.

To guarantee zero downtime and a seamless experience for end-users:
1. All repositories (`CategoryRepository`, `UnitRepository`, `WarehouseRepository`, `ProductRepository`, `SupplierRepository`, `CustomerRepository`, `TransporterRepository`, `VehicleRepository`, `PaymentMethodRepository`, `BomRepository`, `DeliveryRepository`, `CustomerPaymentRepository`, `QualityCheckRepository`, `ExpenseRepository`) maintain an in-memory override cache (`_cachedOverrides` and `_deletedIds`).
2. When the backend IIS server returns 405, the repository automatically falls back to updating the local state, so the UI updates instantaneously.
3. The server-side permanent resolution has been documented in `BACKEND_API_ISSUES.md` (`<remove name="WebDAVModule" />`).
