# Durvaeco Flutter Application

Enterprise Standalone Flutter Application built on clean layered architecture, Riverpod, and GoRouter.

## Documentation
For complete architectural details, guidelines, and conventions, review the [Architecture Blueprint Docs](file:///C:/workspace/durvaeco/docs/README.md).

## Quick Start
```bash
# 1. Install dependencies
flutter pub get

# 2. Run with compile-time configuration
flutter run --dart-define=API_BASE_URL=http://localhost:3030

# 3. Run automated tests
flutter test
```
